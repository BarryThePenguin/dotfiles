# Issue tracker

Issues and PRDs for this repo live in the selected issue tracker. Use the Pi
extension tools for all operations. The extension is tracker-agnostic: the same
tool surface speaks to whichever tracker the working directory selects.

## Conventions

- **Create an issue**: `issue_create({ title, body?, labels? })` → `{ id, url }`.
  `to-spec` and `to-tickets` apply the `ready-for-agent` label at creation.
- **Read an issue**: `issue_read({ id })` → the full issue, including its body,
  labels, status, comments, and timestamps. Accepts an id or URL.
- **List issues**: `issue_list({ state?, labels?, unlabeled? })` with appropriate
  state and label filters. Results are oldest first.
- **Comment on an issue**: `issue_comment({ id, body })`. Every triage comment
  must start with `> *This was generated by AI during triage.*`.
- **Apply / remove labels**: `issue_label({ id, add?, remove? })`. This uses
  delta semantics; it never blindly replaces the existing labels.
- **Close**: `issue_close({ id, comment? })` → `{ status: "closed" }`.
  A closing comment is posted atomically with the close.

Issue references are task ids or URLs. Bare `#42` / `!67` references do not
resolve through the tools; look up the task using the id or URL written in the
reference.

## When a skill says "publish to the issue tracker"

Create an issue with `issue_create` — or use `wayfinder_chart` /
`wayfinder_create_ticket` for Wayfinder resources.

## When a skill says "fetch the relevant ticket"

Use `issue_read` with the task's id or URL — or use
`wayfinder_get_map` / `wayfinder_get_ticket` for Wayfinder resources.

## Wayfinding operations

Used by `/wayfinder`. The **map** is an issue carrying the
`wayfinder_map` label; its child issues are the tickets.

- **Map**: `wayfinder_chart` — creates the map with Destination, Notes,
  Decisions-so-far, Fog, and Out-of-scope sections.
- **Child ticket**: `wayfinder_create_ticket` — creates a child issue under the
  map with a `wayfinder_<type>` label (`research`/`prototype`/`grilling`/`task`).
- **Blocking**: where the selected tracker has no native blocking relationship,
  `wayfinder_set_blocking` records blocker links in the ticket body. A ticket is
  unblocked when every listed blocker is closed.
- **Frontier**: `wayfinder_list_frontier` lists open, unblocked, unclaimed child
  tickets.
- **Claim**: `wayfinder_claim` records the claim in the ticket body. Claiming
  is the session's first write.
- **Resolve**: `wayfinder_resolve` posts the resolution, closes the ticket, and
  appends a context pointer and gist to the map's Decisions-so-far.
